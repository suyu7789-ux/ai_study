## 操作步骤

### Step 1 · 确认 uv 项目与虚拟环境
- **做了什么**：确认上个窗口装好的环境可用，理解 uv 在 Python 里对应 Java 的什么。
- **命令**：
  ```bash
  uv --version
  uv run python --version          # Python 3.12.13
  uv run python -c "import requests; print('requests', requests.__version__)"  # 2.34.2
  ls -a
  ```
- **对照 Java**：`uv` ≈ Maven+JDK 版本管理；`pyproject.toml` ≈ `pom.xml`；`uv.lock` ≈ 依赖锁定；`.venv/` ≈ 项目专属依赖沙箱（≈ `target/` 那样每项目隔离）；`.python-version` ≈ 指定 JDK 版本。
- **坑**：`--verison` 拼错应为 `--version`；模块名是 `requests`（带 s），写成 `request` 会在**运行时**报 `NameError`（Python 无编译期检查）。

### Step 2 · 清掉旧 git 历史，从零开始
- **命令**：
  ```bash
  rm -rf .git          # 删旧仓库历史（不动代码文件）
  git status           # 故意报错 fatal: not a git repository = 干净了
  ```

### Step 3 · git init + 配置作者身份（只对本仓库）
- **命令**：
  ```bash
  git init
  git config user.name  "suyu7789-ux"
  git config user.email "226255802+suyu7789-ux@users.noreply.github.com"
  ```
- **概念**：git 身份分**全局**(`--global`，写 `~/.gitconfig`) 和**本地**(仅当前仓库 `.git/config`)。公司电脑上只给学习仓库设**本地**身份，不污染公司项目。邮箱用 GitHub 的 **noreply 隐私邮箱**，历史里不暴露真实/公司邮箱。

### Step 4 · 检查 .gitignore（黑名单）
- **概念**：`.gitignore` ≈ Java 忽略 `target/`、`*.class`、`.idea/`。关键忽略：`.venv`（≈ `target/`，几百 MB 依赖，能重建，绝不进仓库）、`__pycache__/`、`*.py[oc]`（≈ `.class` 字节码缓存）。

### Step 5 · 第一次提交 + 清理误提交文件
- **命令**：
  ```bash
  git branch -M main               # 默认分支改名 main
  git add .                        # . = 当前目录全部（.gitignore 里的自动跳过）
  git status                       # 红色未追踪 → 绿色已暂存
  git commit -m "chore: 初始化 AI 学习仓库（uv 项目 + 学习路线）"
  # 发现误提交了 .DS_Store，清理：
  echo ".DS_Store" >> .gitignore   # >> 追加，别用 > (会覆盖)
  git rm --cached .DS_Store        # --cached = 只从仓库移除，不删磁盘文件
  git commit -m "chore: 忽略 macOS 的 .DS_Store"
  git log --oneline                # 2 个 commit
  ```
- **概念**：`git add`(暂存/购物车) → `git commit`(下单/版本快照，存**本地** .git)。提交信息用 Conventional Commits 前缀：`feat`/`fix`/`chore`/`docs`。`.DS_Store` 是 macOS Finder 生成的垃圾文件，不该进仓库。

### Step 6 · 连接远程并推送到 GitHub
- **命令**：
  ```bash
  git remote add origin https://github.com/suyu7789-ux/ai_study.git
  git branch -M main
  git push -u origin main
  ```
- **概念**：`commit` 只存**本地**，`push` 才上传到 **GitHub**（Git 是分布式，区别于 SVN）。`origin` = 远程仓库别名；`-u` 绑定本地/远程分支，之后只需 `git push`。
- **坑**：① HTTPS push 认证**不能用登录密码**，Password 处要填 **Personal Access Token (PAT)**（`repo` 权限，只显示一次要存好）。② 国内直连 GitHub 会偶发 `Failed to connect port 443` 超时，重试即可。
- **产出**：仓库上线 → https://github.com/suyu7789-ux/ai_study

### Step 7 · Python REPL 交互环境初体验
- **命令**：`uv run python` 进入 `>>>`，逐行试 `1+1` / `print()` / `type()`，`exit()` 退出。
- **对照 Java**：变量无需声明类型（动态类型，运行时才定）；布尔是 `True/False`（首字母大写）；REPL 自动打印表达式结果，无需 `System.out.println`。

### Step 8 · 清理手滑重定向产生的垃圾文件 DS_Store
- **起因**：之前误敲 `git rm --cached >DS_Store`，shell 的 `>` 是**重定向**，会先凭空创建一个叫 `DS_Store`（无点）的空文件。`.gitignore` 里写的是 `.DS_Store`（有点），匹配不上，于是 `git add .` 把它一起提交了。
- **命令**：
  ```bash
  ls -l DS_Store                   # 确认是 0 字节空文件
  git rm DS_Store                  # 不加 --cached：git 和磁盘一起删（因为它是垃圾）
  git commit -m "chore: 删除手滑重定向产生的垃圾文件 DS_Store"
  git push
  ls -a                            # 确认只剩 .DS_Store(系统文件)，无点的 DS_Store 已消失
  ```
- **概念对比**：`git rm --cached 文件`=只从仓库移除、磁盘保留（文件有用只是不该进仓库，如 `.venv`）；`git rm 文件`=仓库+磁盘一起删（文件是垃圾）。shell `>`=覆盖/新建，`>>`=追加。

### Step 9 · list / dict / set（对照 Java 集合）
- **产出文件**：`week1/01_collections.py`（在 PyCharm 里新建并运行）
- **代码**：
  ```python
  # ============ list（列表）≈ Java 的 ArrayList ============
  langs = ["Java", "Python", "Go"]
  langs.append("C++")            # 加元素，≈ list.add()
  print("列表:", langs)
  print("第一个:", langs[0])      # 下标从 0 开始
  print("最后一个:", langs[-1])   # 负索引：-1 = 倒数第一个
  print("切片 前两个:", langs[0:2])  # 切片 [起,止)：取下标 0、1
  print("长度:", len(langs))      # 用 len()，不是 .size()/.length

  # ============ dict（字典）≈ Java 的 HashMap ============
  user = {"name": "suyu", "age": "21", "job": "Java后端"}
  print("\n字典:", user)
  print("取值:", user["name"])           # 按 key 取值 ≈ map.get()
  user["city"] = "上海"                   # 加/改键值对 ≈ map.put()
  print("age 是否存在:", "age" in user)   # in 判断 key ≈ containsKey()
  for key, value in user.items():         # ≈ entrySet()
      print(f"  {key} = {value}")

  # ============ set（集合）≈ Java 的 HashSet：去重、无序 ============
  tags = {"ai", "Java", "ai", "Python", "java"}  # 重复自动去掉
  print("\n集合(自动去重):", tags)
  tags.add("agent")
  print("agent 是否在 tags:", "agent" in tags)
  ```
- **运行 & 结果**：
  ```
  $ uv run python week1/01_collections.py
  列表: ['Java', 'Python', 'GO', 'C++']
  第一个: Java
  最后一个: C++
  切片 前两个: ['Java', 'Python']
  长度: 4
  字典: {'name': 'suyu', 'age': '21', 'job': 'Java后端'}
  取值: suyu
  判断字段是否存在字典: True
    name=suyu
    age=21
    job=Java后端
    city=上海
  集合, 重复的自动去除: {'ai', 'Java', 'java', 'Python'}
  agent是否在tags中: True
  ```
- **知识点 / 对照 Java**：
  - `list` ≈ `ArrayList`、`dict` ≈ `HashMap`、`set` ≈ `HashSet`。
  - `len(x)` 取长度（不是 `.size()/.length`）；负索引 `langs[-1]` 取倒数；切片 `langs[0:2]` = `[起,止)` 左闭右开；`x in y` 判断存在（≈ `containsKey`/`contains`）；遍历字典 `for k,v in d.items()`（≈ `entrySet()`）。
- **坑 / 要点**：
  - **set 无序 + 自动去重**：打印顺序≠书写顺序（哈希存储，≈ `HashSet`）。
  - **dict 有序**：Python 3.7+ 的 dict 保持插入顺序（≈ `LinkedHashMap`）。
  - **字符串区分大小写**：`"Java"` 与 `"java"` 是不同元素。
  - **加不加引号决定类型**：`"age":"21"` 是字符串 `'21'`，`"age":21` 才是整数 `21`——Python 动态类型不报错，要自己看清。
  - **缩进即语法**：`for`/`if` 下的代码块靠 4 空格缩进划分（≈ Java 的 `{}`），缩进错报 `IndentationError`。

### Step 10 · 列表推导式 + f-string
- **产出文件**：`week1/02_comprehension.py`
- **代码**：
  ```python
  # ============ f-string：字符串模板（≈ String.format / %s）============
  name = "suyu"
  age = 21
  print(f"我叫 {name}，今年 {age} 岁")   # 变量直接塞进 {}
  print(f"明年 {age + 1} 岁")            # {} 里能写表达式、能算数
  price = 9.9
  print(f"单价 {price:.2f} 元")          # :.2f 保留 2 位小数（≈ %.2f）

  # ============ 列表推导式：一行生成/加工列表 ============
  squares = [x * x for x in range(1, 6)]              # range(1,6)=1..5（含头不含尾）
  print("平方:", squares)
  even_squares = [x * x for x in range(1, 11) if x % 2 == 0]  # 带条件 = filter+map
  print("偶数的平方:", even_squares)
  langs = ["java", "python", "go"]
  upper = [s.upper() for s in langs]                 # 加工每个元素
  print("大写:", upper)

  # ============ 字典推导式 ============
  names = ["Tom", "Jerry", "Spike"]
  name_len = {n: len(n) for n in names}              # key=名字, value=长度
  print("名字长度:", name_len)
  ```
- **运行 & 结果**：
  ```
  $ uv run python week1/02_comprehension.py
  我叫 suyu，今年 21 岁
  明年 22 岁
  单价 9.90 元
  平方: [1, 4, 9, 16, 25]
  偶数的平方: [4, 16, 36, 64, 100]
  大写: ['JAVA', 'PYTHON', 'GO']
  名字长度: {'Tom': 3, 'Jerry': 5, 'Spike': 5}
  ```
- **知识点 / 对照 Java**：
  - **f-string**：`f"...{变量}..."`，`{}` 里可放变量/表达式/格式化。比 Java 字符串拼接、`String.format` 简洁得多。格式化 `{price:.2f}` ≈ `%.2f`。
  - **列表推导式** `[表达式 for 元素 in 可迭代对象 if 条件]`：一行完成 Java 里"新建 list + for 循环 + add"三步。读法：先看 `for...in`（数据来源）、`if`（筛选），再看最前面的表达式（每个元素变成什么）。
  - **字典推导式** `{k: v for ... in ...}`：同理一行生成 dict。
  - **`range(a, b)`**：`a..b-1`，**含头不含尾**（左闭右开），和切片 `[a:b]` 规则一致。

### Step 11 · 函数、默认参数、*args/**kwargs
- **产出文件**：`week1/03_functions.py`
- **代码**：
  ```python
  # 基本函数：def 定义（不用写在类里）
  def greet(name):
      return f"Hello {name}"
  print(greet("suyu"))

  # 默认参数（≈ Java 要靠方法重载）
  def greet2(name, greeting="你好"):
      return f"{greeting}，{name}"
  print(greet2("suyu"))              # 用默认
  print(greet2("suyu", "早上好"))     # 覆盖默认

  # 关键字参数：调用时指名道姓传，顺序可反（Java 没有）
  print(greet2(name="苏语", greeting="Good night"))

  # *args：任意多个位置参数 → 打包成 tuple
  def total(*nums):
      print("接收到的参数:", nums)
      return sum(nums)
  print("求和:", total(1, 2, 3, 4, 5, 6))

  # **kwargs：任意多个关键字参数 → 打包成 dict
  def build_user(**kwargs):
      print("收到的键值:", kwargs)
      return kwargs
  build_user(name="suyu", age=21, job="Java后端")
  ```
- **运行 & 结果**：
  ```
  Hello suyu
  你好，suyu
  早上好，suyu
  Good night，苏语
  接收到的参数: (1, 2, 3, 4, 5, 6)
  求和: 21
  收到的键值: {'name': 'suyu', 'age': 21, 'job': 'Java后端'}
  ```
- **知识点 / 对照 Java**：
  - `def` 定义函数，**不用写在类里**（Java 方法必须在类里）。
  - **默认参数** `greeting="你好"` ≈ Java 靠方法重载才能实现。
  - **关键字参数** `greet2(name=.., greeting=..)`：调用时指名传、顺序可反（Java 只能按位置）。
  - **`*args`**（一个星）：收集位置参数成**元组** ≈ Java 可变参数 `String... args`。
  - **`**kwargs`**（两个星）：收集关键字参数成**字典**（Java 无对应，得传 `Map`）。
  - 名字 `args/kwargs` 只是约定，关键是 `*` 和 `**`；读 AI 框架源码时到处都是。

### Step 12 · 装饰器（≈ Spring AOP / 注解切面）
- **产出文件**：`week1/04_decorator.py`
- **代码**（自己扩展成了"日志 + 计时器"装饰器）：
  ```python
  import time

  # 装饰器本质：接收函数、返回新函数的函数
  def log_and_timer(func):             # func = 被装饰的原函数
      def wrapper(*args, **kwargs):    # 用 *args/**kwargs 接住任意参数
          start = time.time()
          print(f"方法{func.__name__}开始执行, 开始时间: {start}s")
          result = func(*args, **kwargs)   # 调原函数、拿返回值
          end = time.time()
          print(f"方法{func.__name__}执行完成, 结束时间: {end}s")
          print(f"方法{func.__name__}执行耗时: {end - start}s, 执行结果: {result}")
          return result               # 把原函数返回值透传出去
      return wrapper

  @log_and_timer                       # ≈ Java 的 @LogExecutionTime
  def slow_add(num1, num2):
      time.sleep(0.5)                  # 睡 0.5 秒模拟耗时
      return num1 + num2

  print(slow_add(1, 2))
  ```
- **运行 & 结果**：
  ```
  方法slow_add开始执行, 开始时间: 1783678011.6057248s
  方法slow_add执行完成, 结束时间: 1783678012.111166s
  方法slow_add执行耗时: 0.5054411888122559s, 执行结果: 3
  3
  ```
- **知识点 / 对照 Java**：
  - **装饰器 = Python 版 AOP**：`@装饰器` 贴在函数上，在**不改原函数代码**的前提下套一层增强逻辑（日志/计时/权限）。≈ Spring 的 `@Transactional`、`@LogExecutionTime`。
  - **`@log` 等价于 `add = log(add)`**：把原函数传进装饰器，返回 `wrapper`，让原函数名指向 `wrapper`。之后调用的其实是 `wrapper`。
  - **为什么 wrapper 用 `*args/**kwargs`**：装饰器要能装饰**任意参数**的函数，用它俩照单全收再原样转发。
  - **记得透传返回值**：`wrapper` 里要 `return result`，否则原函数的返回值会丢。
- **坑**：`time.time()` 返回的是**秒**（带小数的 Unix 时间戳，自 1970 年起），不是毫秒。想要毫秒需 `*1000`（Java 的 `System.currentTimeMillis()` 才是毫秒）。一开始误标成 `ms`，改成 `s` 后与 `sleep(0.5)` 吻合。

### Step 13 · 类型注解（type hint，≈ Java 类型但不强制）
- **产出文件**：`week1/05_type_hints.py`
- **代码**：
  ```python
  # 基本注解：参数: 类型，返回值 -> 类型
  def add(num1: int, num2: int) -> int:
      return num1 + num2
  def greet(name: str) -> str:
      return f"Hello, {name}"
  print(add(10, 1))
  print(greet("suyu"))

  # 复杂类型：容器元素类型也能标
  def total(nums: list[int]) -> int:
      return sum(nums)
  def get_user() -> dict[str, str]:      # 标称值都是 str
      return {"name": "suyu", "age": "21", "job": "Java后端"}
  print(total([1, 3, 43]))
  print(get_user())

  # ⚠️ 关键实验：注解不强制。add 标着要 int，偏传字符串
  print(add("Java", "Python"))
  ```
- **运行 & 结果**：
  ```
  11
  Hello, suyu
  47
  {'name': 'suyu', 'age': '21', 'job': 'Java后端'}
  JavaPython          # ← 没报错！注解写 int 却传 str，字符串 + 是拼接
  ```
- **知识点 / 对照 Java（本步核心）**：
  - **类型注解只是"提示"，运行时完全不检查**（type *hint* 不是 type *check*）。标 `int` 传 `str` 照样运行——本例输出 `JavaPython`（`+` 拼接），程序不报错、退出码 0。
  - PyCharm 会黄字警告"应为类型 'int'，但实际为 'str'"，但**不拦运行**。这与 Java 编译期强制类型是本质区别。
  - **另一种情况**：`total("java")` 会报 `TypeError`——但不是注解检查，而是函数体内 `sum("java")` 这个操作本身做不了（`0 + "j"`），错误拖到运行时才暴露。
  - **注解的价值**：① IDE 自动补全 + 警告；② 可读性（看签名即知传参/返回）；③ **AI 开发地基**——后面 Pydantic、Function Calling 的参数 schema 全靠类型注解定义结构化数据。
  - 写法对照：`def f(x: int) -> int:` ≈ Java `int f(int x)`；容器 `list[int]`、`dict[str, str]`。

### Step 14 · requests 调公开 REST API（本周产出物 🎯）
- **产出文件**：`week1/06_requests_api.py`
- **代码**：
  ```python
  import requests   # Python 版的 RestTemplate / OkHttp

  # ① 最简单的 GET
  url = "https://api.github.com/users/suyu7789-ux"
  resp = requests.get(url)                 # ≈ restTemplate.getForObject(...)

  # ② HTTP 状态码
  print("状态码:", resp.status_code)        # 200 = 成功

  # ③ JSON → dict（requests 内置，一行搞定）
  data = resp.json()                        # Java 得用 Jackson/Gson 手动反序列化
  print("返回数据:", data)

  # ④ 从 dict 取字段
  print("用户名:", data["login"])
  print("用户id:", data["id"])
  print("公开仓库数:", data["public_repos"])
  print("注册时间:", data["created_at"])

  # ⑤ 带查询参数的 GET
  search_url = "https://api.github.com/search/repositories"
  params = {"q": "language:python", "sort": "stars", "per_page": 3}
  resp2 = requests.get(search_url, params=params)   # 自动拼成 ?q=...&sort=...
  print("\n=== Python star 最多的 3 个仓库 ===")
  for repo in resp2.json()["items"]:
      print(f"  {repo['full_name']}  ⭐{repo['stargazers_count']}")
  ```
- **运行 & 结果**：
  ```
  状态码: 200
  用户名: suyu7789-ux
  用户id: 226255802
  公开仓库数: 3
  注册时间: 2025-08-13T07:18:00Z

  === Python star 最多的 3 个仓库 ===
    public-apis/public-apis  ⭐449065
    EbookFoundation/free-programming-books  ⭐391679
    donnemartin/system-design-primer  ⭐357166
  ```
- **知识点 / 对照 Java**：
  - `requests.get(url)` ≈ `restTemplate.getForObject`；`resp.status_code` ≈ `getStatusCode()`。
  - **`resp.json()`**：直接把 JSON 响应转成 dict，无需像 Java 那样写 DTO + Jackson/Gson 反序列化——Python 做 AI 胶水层的优势所在。
  - **`requests.get(url, params={...})`**：字典自动拼成 `?q=..&sort=..` 查询串（≈ `UriComponentsBuilder`）。
  - **通往 Week 2**：调大模型 API 本质就是 `requests.post(url, json={...}, headers={Authorization})`，这套流程原样复用。
